## 2. ハンター側

### H1. ログイン（US1.1）

```
+--------------------------------+
| MonsterNote                    |
|                                |
| ID                             |
| [____________________________] |
| パスワード                [表示] |
| [____________________________] |
|                                |
| [         ログイン          ]   |
+--------------------------------+
```

- エラー: 入力欄の下に ⚠ アイコンと「ID かパスワードが違います」。入力した ID は残す。
- 読み込み中: ボタンの中に回転の表示と「ログインしています」。

### H1a. パスワードの変更（初回・再設定のあと）（US1.2）

```
+--------------------------------+
| 新しいパスワード                |
| 8文字以上で、英字と数字を       |
| 両方入れてください。            |
| [____________________________] |
| もう一度                        |
| [____________________________] |
| [          変える           ]   |
+--------------------------------+
```

- 初回ログインの順番は「H1a パスワード変更 → H1b 同意 → H1c 従事者番号 → H2 ホーム」（依頼元は H1a のあと一覧へ）。

### H1b. 同意（US1.3）

- 説明文（報告の氏名・位置・写真を依頼元に見せること、試験運用の終了時に削除すること）と、[ 同意する ]（主）・[ 同意しない ] の 2 ボタン。
- 「同意しない」: 「同意がないと報告できません。問い合わせ: 管理者」を表示。

### H1c. 従事者番号（US1.4）

- 数字キーボードの入力欄 1 つと [ 登録 ]。空のときは ⚠「番号を入れてください」。

### H2. ホーム（US5.1・US5.3）

```
+--------------------------------+
| MonsterNote            [≡]     |
|                                |
| [     ＋ 報告する（大）     ]   |
|                                |
| 自分の報告                      |
| +----------------------------+ |
| | 11/20 イノシシ  ⏳確認中    | |
| | 送ってから 3日              | |
| +----------------------------+ |
| | 11/18 シカ      ✔承認       | |
| +----------------------------+ |
| | 11/15 クマ      ✖却下       | |
| +----------------------------+ |
+--------------------------------+
```

- 確認中で 7 日を過ぎた報告: カードの下に ⚠「依頼元の確認に時間がかかっています。急ぐときは依頼元に連絡してください」。
- 下書きは表示しない（下書きはない）。空のときは「まだ報告はありません。上の『報告する』から始めます」。
- [≡] メニュー: ホーム、ログアウト。

### H3. 写真（全身 1/7・尻尾 2/7）（US2.2・US2.3）

```
+--------------------------------+
| ← 戻る         1/7  [やめる]   |
| ■□□□□□□                       |
| 全身の写真                      |
| <手本の絵>                      |
| 体に日付と番号を書き、          |
| 全身が写るように撮ります。      |
|                                |
| [        📷 撮る         ]     |
| [        🖼 選ぶ         ]     |
+--------------------------------+
```

- 撮った・選んだあと: 写真を大きく表示し、[ この写真を使う ]・[ 撮り直す ]。日時・位置が読めたら「📍 日時と場所を読み取りました」、読めなければ「日時か場所が写真にありません。あとで入れます」。
- 15 MB を超える、画像でない、JPEG に変えられない: ⚠ と理由、選び直し。
- 尻尾（2/7）も同じ形。

### H4. 種類（3/7）（US2.6）

```
+--------------------------------+
| ← 戻る         3/7  [やめる]   |
| 種類                            |
| <全身の写真（小）>              |
| AI の判定: イノシシ（92%）      |
| ( ● イノシシ               )   |
| ( ○ クマ                   )   |
| ( ○ シカ                   )   |
| [          次へ            ]   |
+--------------------------------+
```

- 80% 未満・判別失敗: 判定の行は「AI では判別できませんでした。選んでください」、何も選ばれていない、[ 次へ ] は押せない。
- 判別中: 「写真から種類を調べています」と進行の棒（10 秒を過ぎたら「手で選べます」と表示し選択肢を有効にする）。
- 選択肢は 3 つの大きなボタン（選んだものは ● と枠と太字）。

### H4b. 胸の写真（クマのとき 4/8）（US2.7）

- H3 と同じ形。案内は「胸の月の輪が全部写るように」。ボタンは [ 📷 撮る ]・[ 🖼 選ぶ ]・[ 撮れなかった ] の 3 つ。

### H5. 雌雄（4/7、クマ 5/8）（US2.8）

- 大きな選択肢 3 つ: オス・メス・不明。選ぶまで [ 次へ ] は押せない。

### H5b. 成獣／幼獣（5/7、クマ 6/8）（US2.9）

- 大きな選択肢 2 つ: 成獣・幼獣。

### H5c. 捕獲の方法（6/7、クマ 7/8）（US2.9）

- 大きな選択肢 3 つ: わな・銃・その他。

### H6. 内容の確認と送信（7/7、クマ 8/8）（US2.10・US2.5）

```
+--------------------------------+
| ← 戻る         7/7  [やめる]   |
| 確認して送る                    |
| <全身> <尻尾> (<胸>)            |
| 種類   イノシシ          [直す] |
| 雌雄   メス              [直す] |
| 成獣／幼獣 成獣          [直す] |
| 方法   わな              [直す] |
| 日時   11/20 8:15        [直す] |
| 場所   {小さな地図} A町  [直す] |
| 番号   12345                    |
|                                |
| [           送る           ]   |
+--------------------------------+
```

- 日時・場所が空白: その行に ⚠「入れてください」と [ 入れる ]（H6a・H6b へ）。[ 送る ] は押せない。
- 7 日より前・未来・対象地域の外: その行に ⚠ と理由（「捕獲日時が 7 日より前です」など）。[ 送る ] は押せない。
- 手入力した行には ✎「手入力」の小さな印。
- 送信中: [ 送る ] の中に回転の表示と「確認しています」、押せない。
- 送信失敗: 画面上部に ⚠「送れませんでした」と [ もう一度 ]。内容は残す。

### H6a. 日時を入れる（Q6）

```
+--------------------------------+
| ← 戻る                          |
| 捕まえた日                      |
| [ 今日 ] [ 昨日 ] [ おととい ]  |
| [ もっと前（カレンダー） ]      |
| 時刻                            |
| [  8 時 ▼ ] [ 15 分 ▼ ]         |
| [          決める           ]   |
+--------------------------------+
```

- 「もっと前」はカレンダーを開くが、7 日より前と未来の日は選べない。

### H6b. 場所を入れる（Q6）

```
+--------------------------------+
| ← 戻る                          |
| 捕まえた場所                    |
| {地図: 印を置く}                |
|                                |
| [   ◎ 今いる場所へ移動    ]    |
| 地図をタップして印を置きます    |
| [          決める           ]   |
+--------------------------------+
```

- 印を置くまで [ 決める ] は押せない。対象地域の外に置くと ⚠「対象地域の外です」。
- 位置の許可がないとき: 「今いる場所」を押すと許可の手順を表示（地図のタップでは入れられる）。

### H7. 重複の疑い（ダイアログ）（US3.2）

```
+--------------------------------+
| よく似た報告があります          |
| 近くで同じ日に、よく似た報告が  |
| あります。同じ個体では          |
| ありませんか？                  |
| ・イノシシ 11/20 8:00 約 300m   |
|                                |
| [ 別の個体なので送る       ]   |
| [ 送るのをやめる           ]   |
+--------------------------------+
```

- 他のハンターの氏名・写真は表示しない。
- 「送るのをやめる」→ H-X（やめる確認）。

### H-X. やめる確認（ダイアログ）（US2.11）

- 「写真と入力内容は消えます。よろしいですか？」と [ 消す ]（危険の色）・[ 続ける ]。全ステップの [やめる] と、ステップ途中のホームへの移動でも同じものを出す。

### H8. 送信完了

- ✔ の大きなアイコン、「送りました。依頼元が確認します」、[ ホームに戻る ]。

### H9. 自分の報告の詳細（US5.2）

- ラフな画面案と同じ。却下のときは理由（「その他」のときは書かれた文）と [ 撮り直して新しく報告する ]。送った内容を直すボタンはない。

## 3. 依頼元側

### R1. ログイン

### R2. 報告の一覧（パソコン: 左に一覧、右に R3）（US4.1・US4.7）

```
+---------------------------------------------------------------------+
| MonsterNote（依頼元）                                   [≡]        |
| 絞り込み: [確認中] [承認] [却下] [重複の疑い] [手入力]  全 51件     |
|---------------------------------------+-----------------------------|
| 日付  ハンター 種類   場所  状態  印   | （R3 報告の詳細）           |
| 11/20 田中   イノシシ A町  ⏳確認中 ⚠重複 |                           |
| 11/20 佐藤   シカ     B町  ⏳確認中 ✎手入力|                         |
| 11/12 鈴木   クマ     A町  ⏳確認中 ⏰7日以上|                        |
|  ...                                   |                             |
| < 1 / 2 >                              |                             |
+---------------------------------------+-----------------------------+
```

- 新しい順、1 ページ 50 件。絞り込みは複数選べるチップ。
- スマホ（〜1023px）: 1 件 1 枚のカード、押すと R3 の画面に切り替え。
- 空: 「報告はまだありません」（絞り込みで 0 件のときは「条件に合う報告はありません」と [ 絞り込みを外す ]）。

### R3. 報告の詳細と確認（US4.2〜US4.6）

```
+-----------------------------------------------+
| 11/20 田中 イノシシ            ⏳確認中        |
| <全身> <尻尾>   （押すと拡大）                |
| 種類 イノシシ（AI: イノシシ 92%）             |
| 雌雄 メス  成獣  わな  番号 12345             |
| 日時 11/20 8:15  場所 {地図} ✎手入力           |
| ⚠ 重複の疑い: 11/20 佐藤 約300m  [見比べる]  |
|                                               |
| [ 承認 ]   [ 却下 ]                           |
+-----------------------------------------------+
```

- [ 見比べる ]: 2 件の写真と項目を左右に並べる（スマホは上下）。
- [ 却下 ]: 理由のダイアログ（重複の疑い／写真が不十分／対象の地域・種類ではない／その他）。「その他」は文字の入力欄が必須。
- 承認・却下のあと: 画面下に「承認しました」と [ 取り消す ]（10 秒の残り時間を表示）。10 秒たつと消える。
- すでに他の人が確認済み: ⚠「すでに確認済みです（承認、佐藤）」を表示し、状態を最新にする。

## 4. 管理者側（パソコン中心）

### A1. 管理者のホーム（US6）

- メニュー: アカウント、設定、操作の記録、データの削除。

### A2. アカウント（US6.1〜US6.3）

```
+-------------------------------------------------------------+
| アカウント                               [＋ 作成]          |
| 氏名    ID       役割    所属    状態   操作                |
| 山田    yamada   ハンター  —      有効   [再設定] [無効にする]|
| 佐藤    sato     依頼元   猟友会  有効   [再設定] [無効にする]|
| 鈴木    suzuki   ハンター  —      無効   [有効に戻す]        |
+-------------------------------------------------------------+
```

- [＋ 作成]: 役割・氏名・ID・（依頼元なら所属）を入れる。作成後、仮のパスワードを 1 回だけ大きく表示し [ 写した ] で閉じる。
- [再設定]・[無効にする]: 確認のダイアログ（対象の氏名を表示）。

### A3. 設定（US6.4）

- 重複の基準: 距離（m）と時間（時間）。対象地域: 地図で中心を置き、半径（km）を入れる。初期値は「日本の範囲」。[ 保存 ] の前に「次に送られる報告から使います」と表示。

### A4. 操作の記録（US6.6）

- 新しい順の表: 日時・誰が・操作・対象。

### A5. データの削除（US6.5）

- 「報告 40 件と写真を削除します。よろしいですか？」のダイアログ。[ 削除する ]（危険の色）は、確認の文字「削除」を入力するまで押せない。
