# Feasibility Assessment — MonsterNote

入力: `ideation/intent-capture/intent-statement.md`（intent-statement）、`ideation/market-research/competitive-analysis.md`（competitive-analysis）、`ideation/market-research/market-trends.md`（market-trends）、`ideation/market-research/build-vs-buy.md`（build-vs-buy）、feasibility-questions.md の回答（Q1〜Q9）、プロジェクトのルール（project.md）。

## 1. 結論

**条件付きで実現可能**。ただし、最初の版を 1 か月以内に出すには、次の Scope Definition で機能を絞る必要がある（Q7・Q8）。とくに「写真からの雌雄の自動判別」と「クマの月の輪による個体の照合」は、1 か月の最初の版では実現の見込みが低い。

## 2. 機能ごとの実現性

評価: 高 ／ 中 ／ 低（1 か月・開発者 1 人＋AI・月 100 円以内という条件での見込み）

| 機能 | 実現性 | 理由 | 根拠 |
|---|---|---|---|
| 写真付きの報告・依頼元の確認（承認・却下） | 高 | 一般的な Web アプリの機能で、サーバレス・無料枠の構成で作れる | intent-statement、技術環境 |
| 位置・日時の自動取得 | 高 | スマホのブラウザから位置情報と撮影日時を取得できる（利用者の許可が必要） | intent-statement |
| 高齢ハンター向けの大きなボタン・選択式 | 高 | 画面設計で対応できる | intent-statement、competitive-analysis |
| 写真からの種類の判別（クマ・イノシシ・シカ） | 中 | AWS の画像認識サービスで判別できる見込み。ただし「イノシシ」と「ブタ」、捕獲後の倒れた状態の写真などで正しく判別できるかは、実際の写真で試すまで分からない。費用は月 150 枚程度なら、アカウント作成から 12 か月は無料枠（月 1,000 枚）に収まる（Q1・Q2） | [Rekognition 料金](https://aws.amazon.com/rekognition/pricing/) |
| 写真からの雌雄の判別（自前の解析ロジック） | 低 | 害獣の雌雄を写真から見分ける公開の手法やモデルは、今回の調査では見つからなかった（market-trends）。作るには学習用の写真を大量に集める必要があり、1 か月では難しい。さらに画像解析の処理は多くのメモリを使う見込みで、プロジェクトのルール（関数のメモリは 128〜256 MB）とぶつかる可能性がある | market-trends、project.md |
| 重複の疑いの検出（場所・日時の近さ） | 高 | 報告どうしの位置と日時を比べれば判定できる | intent-statement |
| 重複の疑いの検出（写真の類似） | 中 | 同じ写真や、ほぼ同じ写真の検出は比較的簡単。別の角度から撮った同じ個体の判定は難しい | intent-statement |
| クマの月の輪による個体の照合 | 低 | 調査でも、見分けられた写真は平均 48.6%。捕獲後の写真で同じように使えるかは未確認（market-trends） | market-trends |
| 登録前にハンターへ重複の疑いを知らせる | 高 | 判定結果を画面に出すだけで実現できる | Market Research の Q6 |
| 捕獲従事者の番号を報告に自動で付ける | 高 | ハンターの登録情報として持てばよい（Q5） | feasibility-questions |
| 国の捕獲確認マニュアルの手順（位置付きの写真・マーキング・尻尾の写真） | 高 | 写真の撮り方の案内と、撮影枚数・種類のチェックで対応できる | market-trends |
| 国の交付金の実績報告に使える記録 | 中 | 必要な項目と書式を最新のマニュアルで確認する必要がある | market-trends |
| お客様への履歴の公開（氏名・位置を含む） | 中 | 機能としては作れる。ハンターの同意を得る仕組み（Q9）と、見せる相手を限る認証が必要 | Q4・Q9 |
| 圏外対応 | 不要 | 電波のある場所で報告する（Q6） | Q6 |

## 3. 費用の見通し

| 項目 | 見通し | 根拠 |
|---|---|---|
| 写真の種類判別 | 月 150 枚程度。12 か月の無料枠（月 1,000 枚）内で 0 円。無料枠が終わった後は 1 枚約 0.001 ドルで、月 0.15 ドル（約 23 円）程度 | Q1・Q2、[Rekognition 料金](https://aws.amazon.com/rekognition/pricing/) |
| そのほかのサーバレスのサービス | 試験運用の規模なら無料枠に収まる見込み。12 か月だけ無料のサービスは、無料枠が終わると少額の費用がかかる | 技術環境、[AWS 無料枠](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/free-tier.html) |
| 合計 | 試験運用の期間中は月 100 円以内に収まる見込み。MonsterNote のタグで費用を分けて確認する（Q3） | Q3 |

## 4. 期限の見通し

最初の版は 1 か月以内に使える状態にする（Q7）。上の表の「低」の機能（雌雄の自動判別、月の輪による照合）と、「中」の一部は、次の Scope Definition で最初の版から外すか、手動の代替（雌雄はハンターが選ぶ、など）にすることを検討する（Q8）。

## 5. 判断が必要な点（次のステージへの引き継ぎ）

- 雌雄の判別: 最初の版は、ハンターが大きなボタンで選ぶ方式（「不明」も選べる）にし、自前の解析ロジックは次の版で検討することを提案する。これは Intent Capture で決めた方針（Q20・Q28・Q30）を変えることになるため、Scope Definition で判断する。
- 関数のメモリの上限（128〜256 MB）と、画像解析の処理の両立。解析ロジックを作る場合は、ルールの見直しを人に確認する。
- 種類の判別が、実際の捕獲写真で使える精度かを、最初の版の作業の早い段階で試す。

## Assumptions & Open Questions

- AWS の画像認識サービスで、クマ・イノシシ・シカを捕獲後の写真から十分な精度で判別できるかは、実際の写真で試すまで分からない。 [assumption]
- 東京リージョンの画像認識の料金は、米国東部と同程度と見込んでいる（未確認）。 [assumption]
