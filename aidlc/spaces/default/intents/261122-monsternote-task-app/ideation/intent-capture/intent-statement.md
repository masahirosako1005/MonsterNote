# Intent Statement — MonsterNote

## Problem Statement

この数年、山から野生動物が街に出没し、さまざまな被害が出ている。こうした害獣（モンスター）を捕獲・駆除するハンターが、その成果を依頼元に報告し、賞金を受け取るための記録（ハンターノート）が必要になっている。 [Q1]

MonsterNote は、ハンターが捕獲・駆除した害獣を写真付きで報告し、依頼元が確認するための Web アプリである。当初の説明にあった「タスク管理」は仮の言い方で、正しくは害獣ハンターの報告アプリである。 [desc] [Q9]

一番の課題は、同じ個体を何度も登録して賞金を二重に得ようとする人がいることである。 [Q1]

## Target Customer

| 利用者 | 得られる価値 | Source |
|---|---|---|
| 地元のハンター（猟師） | スマホ・タブレットから、写真付きの報告を少ない入力で提出できる。高齢の人が多いため、大きいボタンや選択式で分かりやすい操作にする | [Q1] [Q2] |
| 依頼元（市町村の担当課、猟友会、農家・農協などの団体） | 提出された報告を確認し、承認・却下を判断できる。重複の疑いがある報告に気づける | [Q2] [Q10] [Q11] [Q13] |
| 報告履歴を参照する人（MVP を管理する本人と同僚、お客様＝自分の勤務先のお客様。アプリの導入を検討する自治体など） | ハンターの報告履歴を参照できる | [Q2] [Q22] [Q25] |

最初の版で求める価値は次のとおり。 [Q11] [Q12] [Q13] [Q19] [Q20] [Q21]

- 報告の証拠として写真を撮り、写真から位置・種類（熊・イノシシなど）・雌雄を自動で判別する。判別できない、または誤判定のときは、ハンターが簡単な手順で手動補正できる。 [Q1] [Q12]
- 種類（熊・イノシシなど）の判別には AWS の画像認識サービス（利用者の指定は Amazon Rekognition）を使う。最初の版では扱う写真が少ないため、費用は月 100 円程度まで受け入れる。 [Q19] [Q26]
- 雌雄の判別は、無料の画像解析ライブラリなどを使った自前の写真解析ロジックで行う。ロジックで判定できない場合は「不明」とし、ハンターが画面の大きなボタンで雌雄を手動で選ぶ（分からないときは「不明」のままにできる）。 [Q20] [Q28] [Q30]
- 種類の判別にかかる費用と、写真解析ロジックで雌雄を見分けられるかは、Feasibility ステージで公開情報から調べて判断する。 [Q31]
- 同じ個体と疑われる報告を、場所・日時・写真の類似を手がかりにアプリが自動で見つけて印を付け、依頼元が最終判断する。具体的な判定方法は、一人で獣を持ち上げるような非現実的な作業を含まない案として後のステージで提案する。 [Q13] [Q14]
- 重複を防ぐため、ハンターは現場で次の作業を行う: 獣の体に日付・印を書いて写るように撮る、尻尾や耳など体の一部を証拠として依頼元に提出する、全身と顔など決まった向きで 2〜3 枚撮る。 [Q21]
- 害獣の種類ごとに個体を見分ける特徴があるかを、次のステージで公開情報から調べ、重複の判定方法の提案に使う。 [Q21] [Q27]
- アプリが扱うのは報告の提出と依頼元の確認（承認・却下）まで。賞金の支払いはアプリの外で行う。 [Q11]

## Success Metrics

最初の版（試験運用）は、次の 3 つをすべて満たしたときに成功とする。 [Q3] [Q18]

| # | 指標 | 判定方法 | Source |
|---|---|---|---|
| 1 | ハンター 3 人以上が、それぞれ 1 件以上の報告を写真付きで提出し、依頼元がすべてを確認（承認・却下）できた | 提出件数・ハンター数・確認済み件数を数える | [Q18] |
| 2 | わざと同じ個体を 2 回報告したテストで、重複の疑いが見つかった | テスト報告に重複の疑いの印が付くことを確認する | [Q18] |
| 3 | AWS の請求額が月 100 円以内（写真の自動判別の費用を含む）に収まっている。当初の「月 0 円」から、自動判別の費用を受け入れるために変更した | 月ごとの請求額を確認する | [Q18] [Q29] [memory:M1] |

## Initial Scope Signal

- ワークフローのスコープ（workflow-selected）: `feature`（機能開発の一通りの流れ）。 [scope]
- 利用者が決めた最初の版の範囲: 試験運用として、ハンター数人と、依頼元として市町村の担当課と猟友会の 2 組織が、実際の捕獲を報告する。 [Q15] [Q23]
- 最初の版から除外する機能は今のところない（履歴の参照、レポート出力、写真の自動判別、重複の検出を含む）。 [Q8] [Q17]
- アプリは GitHub で公開し、AWS にデプロイする。GitHub リポジトリは公開のため、秘密情報は含めない。 [desc] [memory:M2]
- 試験運用のあとに、ハンター・依頼元から直接意見を聞き、次の版に取り入れる。 [Q16] [Q24]
