# Stakeholder Map — MonsterNote

## Key Stakeholders and Interests

| ステークホルダー | 関心ごと | Source |
|---|---|---|
| 開発者（プロダクトオーナー本人） | 何を作るか・何を優先するかを決める。AI-DLC2 の手順を教材にまとめ、サーバレスを無料枠内で作る練習をする。MVP を管理し、報告履歴を参照する | [Q4] [Q16] [Q22] |
| 同僚 | MVP の管理に関わり、報告履歴を参照する | [Q22] |
| お客様（自分の勤務先のお客様。アプリの導入を検討する自治体など） | 報告履歴を参照し、アプリの導入を検討する | [Q22] [Q25] |
| 地元のハンター（猟師） | 捕獲・駆除した害獣を、少ない入力・分かりやすい操作で写真付きで報告し、賞金を受け取る | [Q1] [Q2] [Q5] |
| 依頼元: 市町村の担当課（試験運用に参加） | 報告を確認して承認・却下する。重複登録による賞金の二重取りを防ぐ | [Q1] [Q10] [Q11] [Q13] [Q23] |
| 依頼元: 猟友会（試験運用に参加） | 報告を確認して承認・却下する。重複登録による賞金の二重取りを防ぐ | [Q1] [Q10] [Q11] [Q13] [Q23] |
| 依頼元: 農家・農協などの団体 | 報告を確認して承認・却下する。試験運用には参加しない | [Q10] [Q23] |
| 動画教材の視聴者 | AI-DLC2 で作る過程と成果物を見る | [Q5] |
