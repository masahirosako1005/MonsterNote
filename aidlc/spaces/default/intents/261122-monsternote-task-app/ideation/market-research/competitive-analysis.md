# Competitive Analysis — MonsterNote

前提: `ideation/intent-capture/intent-statement.md`（intent-statement）。MonsterNote は、害獣を捕獲・駆除したハンターが写真付きで報告し、依頼元が確認する Web アプリである。一番の課題は、同じ個体の重複登録による賞金の二重取りである。

## 1. 競合（既存の捕獲報告の手段）

| 種類 | 例 | 概要 | 出典 |

## 3. 差別化の方針

市場調査の回答で決めた MonsterNote の強みは次の 3 つ（market-research-questions.md の Q2）。

1. **同じ個体の重複登録の自動検出** — 場所・日時・写真の類似から疑いを見つけて依頼元に知らせる。クマは胸の月の輪を補助的な手がかりに使う（Q5）。登録前にハンター本人にも「同じ個体ではありませんか」と確認する（Q6）。公開情報では、個体の重複検出をうたう既存製品は見つからなかった（仮説: 差別化の余地がある）。
2. **高齢ハンターでも迷わない操作** — 大きなボタンと選択式で、入力を少なくする。
3. **運用費がほぼかからない** — 小さな市町村や猟友会でも使える。

注意（仮定）: 圏外での利用は既存製品の多くが対応している。山中で使う場面が多いなら、MonsterNote の弱みになる可能性がある。要件の段階で確認が必要。
