## 2. 見つけて直したバグ: 計測スクリプト自身が固定の緯度経度を使っていた

1回目の実行は、`POST /v1/reports`が`409 DUPLICATE_SUSPECTED`で失敗して途中で止まった。原因は`scripts/perf-check.ts`が毎回同じ緯度経度（`lat: 35.0, lng: 135.0`）・同じ種類（`deer`）で送信しており、当日すでに`npm run smoke`で同じ場所に送信済みの報告と重複の疑いに引っかかったため（スモークテストと計測スクリプトのどちらも固定座標を使う設計だった）。

`scripts/perf-check.ts`を修正し、送信のたびに緯度経度に小さな乱数のずれ（±0.05度≈5.5km。重複判定の既定の距離しきい値よりずっと大きい）を加えるようにした。修正後、`npx tsc --noEmit -p scripts/tsconfig.json`で型を確認し、再実行してすべて成功した。
