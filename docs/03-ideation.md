## ゴール
- `/aidlc` に作りたいもの（タスク管理 Web アプリ「MonsterNote」）を伝え、Ideation フェーズの各ステージを完了する
- 各ステージで AI から出た質問・自分の回答・承認ゲートでの判断を時系列で残す

## 記録の読み方
- **AI の質問** … AI-DLC が出した質問（選択肢を含む）
- **回答** … 自分が選んだ／入力した内容
